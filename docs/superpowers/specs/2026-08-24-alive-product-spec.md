# PigeonX Product Upgrade: The Smartest and Most Alive Bird-Deterrent App
(Owner spec, received 2026-08-24. Verbatim.)

Objective: PigeonX should feel like an intelligent protection system for a specific place, not simply an app that plays sounds. Within three seconds of opening, the user knows: which place they are protecting, which birds they are targeting, whether protection is active, which sound and speaker are selected, and what will happen next.

Core model: Place + Target bird + Protection plan. Free = one place; Pro/Business = multiple.

Personalized setup questions: birds causing the problem (Pigeons / Gulls / Starlings / Crows or jays / Small mixed birds / Not sure); what is being protected (Balcony / Roof / Dock or marina / Storefront / Warehouse / Parking structure / Garden / Farm or field / Custom); area size; people nearby; audible limits; phone or PigeonX speaker; when birds appear; place name. Recommendations are recommendations, never guaranteed results.

Home: place switcher header (PLACE / target · output). Four states: OFF ("Ready when birds appear."), ACTIVE (plan + countdown), SCHEDULED (next session time), NEEDS ATTENTION (offline speaker). Mascot as functional state indicator (calm, looking at Start, calling with sound lines, clock pairing, looking at offline speaker, walking off when complete); minimal and graphic, not childish. Live session screen: sound, output, countdown, volume, pitch, audible warning, pause, stop, next-in-rotation, speaker status, subtle waveform. Post-session: "Did the birds leave?" Yes / Some left / Not yet / I could not tell; factual summaries only from user-reported data.

Sounds: personalized sections (Recommended for <place>, Natural recordings, Variable tones, Speaker-only). Cards: preview, short waveform, exact name, natural/generated, target species, frequency labels as explicit words ("Low frequency", "High frequency", "18 kHz", "22 kHz"; never LOW/HIGH/VERY HIGH), audible status ("Audible" / "May be audible" / "Typically inaudible"), environment, Pro status, credits. No "Most effective" or unsupported claims. Do not mark 22 kHz audible; do not imply every phone reproduces exact frequencies.

Protection plans: target species, sounds, randomized order, interval, session length, output, volume, quiet hours, active days, date range. Default "Pigeon Rotation": distress + hawk, randomized intervals, 15-minute session, audible warning. Randomization reduces predictability; never claim it guarantees non-adaptation.

Schedule: real timeline (today + upcoming, start/end, place, plan, output, status, quiet hours, next run). Triggers: time, sunrise, sunset, weekdays, date range. Personalized empty state.

Places & devices: smart-home-style place list with status lines; per-speaker online/offline, place, last connection, volume, active plan, next session, software status, battery when supported. Never fake hardware data.

History: activity timeline (time, plan/sound, place, duration, output, result), filters (place, sound, device, result, date); Business sees all locations.

Business: property-control system. Locations, areas, fleet, staff access, speaker health, schedules, problems, central history, reports. Dashboard summary tiles. Copy: "$29/month per location"; "Managing a larger portfolio? Contact us for custom pricing."

Settings structure: Account and plan / Places and speakers / Appearance / Activity / Help (adds Choosing a sound, Choosing a speaker, Audible-sound safety, Speaker placement, Audio credits) / standard labels (Restore purchases, Terms, Privacy).

Paywall: hero must scroll away or collapse; never cover pricing/purchase. Benefits as outcomes (lists per Pro/Business).

Alive feeling: real state changes only (mascot state, sound lines during playback, visible countdown, in-place speaker status, sessions appear in history immediately, schedule cards flip upcoming→active, subtle blue confirmation flash, restrained haptics, clear offline warning). Never fake bird counts, detection, or effectiveness data.

Safety & credibility: mark audible sounds, warn before loud audible playback, reasonable-volume guidance, placement help, quiet hours, exact species names, credits, no guaranteed outcomes, no ultrasonic-parity claims.

Priorities:
- P0 credibility: paywall overlap; Sounds footer covering content; audible-frequency labels; remove unsupported effectiveness claims; exact bird/recording names; audio credits; all bottom safe-area/scrolling issues.
- P1 personalization: target-bird onboarding; named places; recommended plans; place switcher on Home; post-session result feedback; History timeline.
- P2 alive state: Active session screen; functional mascot states; live speaker status; Schedule timeline; plan rotation; subtle motion + haptics.
- P3 business: locations/areas; fleet health; central history; staff access; location schedules and reporting.

Acceptance: 3-second understanding on open; whole interface visibly active during playback; app learns from the user's reported result.
