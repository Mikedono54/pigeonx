> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the PigeonX monorepo, shared core package (tokens, entitlements, audio profiles), and the Supabase backend (schema + RLS + seed) so the mobile and web apps can be built against real contracts.

**Architecture:** pnpm workspace with `apps/mobile`, `apps/web`, `packages/core`, `supabase/`. `packages/core` is the single source of truth for design tokens, tier gates, audio profile definitions and DB types. Supabase hosted project `pigeonx` (org "SnapMind AI" for now; transferable), migrations applied with `supabase db push`, RLS verified with a node script using anon + service keys (no Docker available locally).

**Tech Stack:** pnpm 11, TypeScript 5, vitest, zod 4, Supabase CLI (via `npx supabase@latest`, already authenticated), Postgres 17.
