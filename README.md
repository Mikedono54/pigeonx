# PigeonX

Smarter, humane bird deterrence for the places people gather.

- `apps/mobile` — iOS/Android app (Expo)
- `apps/web` — pigeonx.org marketing site + Business/Enterprise dashboard
- `packages/core` — shared tokens, entitlements, audio profiles, DB types
- `supabase/` — schema, RLS, RPCs, seed

Docs: `docs/superpowers/specs`, `docs/superpowers/plans`, `design-system/pigeonx/MASTER.md`.
